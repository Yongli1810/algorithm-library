# 算法资源库 | Algorithm Library

按算法大类整理算法学习与实践资源。每个算法统一整理 **说明文档、代码与运行材料和演示视频**，方便查阅原理、运行代码和查看演示效果。

## 分类与目录

采用“大类 → 子类 → 算法”的三级目录结构。每个算法目录提供 README，注明作者、分类、原始压缩包和资源状态。

```text
优化算法/
├── 多目标优化/NSGA-II/
└── 随机优化/模拟退火/
机器学习/
├── 聚类/K-means/
├── 聚类/DBSCAN/
└── 分类/KNN手写数字识别/
图像处理/
├── 图像分割/灰度阈值二值化/
└── 边缘检测/Sobel/
来源记录/
```

## 单个算法的资源规范

每个算法目录统一使用以下资源名称，另附 README.md 记录作者和资源状态：

| 文件 | 内容要求 |
| --- | --- |
| `说明文档.docx` | 算法简介、基本原理、关键公式或流程、参数说明、使用场景及参考资料 |
| `代码/` | 可运行源码、依赖说明、运行步骤及必要的示例数据 |
| `演示视频.mp4` | 运行过程、参数设置及结果展示 |

代码目录中建议包含 `README.md`，说明编程语言、运行环境、依赖安装方式、运行入口和预期输出。涉及随机过程的算法，建议注明随机种子设置方法。

资源缺失时，在算法索引中标注“待补充”，不创建空的压缩包或视频文件。

视频较大时，可使用 GitHub Releases 或外部视频存储，并在算法索引中提供链接；在索引中注明实际存放位置。

## 本地上传说明

本目录为可手动上传的仓库文件，不包含 `.git`。代码已解压到各算法的 `代码/` 目录，整理目录不保留 ZIP 压缩包。上传时保留完整目录层级，根目录 README.md 用于覆盖远程首页。

## 使用方法

1. 在算法索引中查找所需算法，并按分类进入对应目录。
2. 阅读说明文档，了解算法原理和参数含义。
3. 下载算法目录，按代码目录内的说明配置环境并运行。
4. 观看演示视频，对照运行过程和结果。

## 新增算法

1. 选择合适的大类与子类；没有合适分类时，再新增分类目录。
2. 创建算法目录，名称优先使用通用中文名或常用英文缩写。
3. 按统一名称添加说明文档、代码目录和演示视频。
4. 更新本 README 的算法索引与收录状态；资源上传后可为算法及文件添加相对链接。
5. 检查文档可打开、代码文件完整且可运行、视频可播放。
