## 运行

使用 Python 3.10 或更高版本，在 `代码/` 目录执行：

```bash
python Knapsack_DP_Python_Code.py
```

重新生成图表需要 Matplotlib。`make_video.py` 为可选的视频制作脚本，依赖与算法主程序不同，详见原包说明。

原包使用说明将入口称为 `knapsack_demo.py`，实际交付文件为 `Knapsack_DP_Python_Code.py`，以上命令以实际文件名为准。
演示采用模拟教学数据，不代表真实应急物资优先级。
