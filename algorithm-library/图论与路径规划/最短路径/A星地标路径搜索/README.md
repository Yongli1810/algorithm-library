# A* 地标路径搜索

在网格地图上进行最短路径搜索，比较曼哈顿距离 A* 与不同地标选择方式的 ALT 启发式搜索。

## 算法与使用

代码包含 Dijkstra、曼哈顿距离 A*，以及角点、最远点、障碍邻域候选地标三种 ALT 搜索方案。
地图允许上下左右移动，每步代价为 1。地标方法需同时考虑预处理成本与查询成本，具体性能取决于地图和查询条件。

推荐使用 Python 3.12。在 `代码/` 目录运行：

```bash
python run.py test
python run.py demo
```

演示命令会生成 `outputs/demo/demo.html`，可用浏览器打开。实验绘图依赖和完整实验步骤见原作者运行说明。
