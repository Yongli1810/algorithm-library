为什么仍然得到最短路

曼哈顿距离忽略障碍；地标距离记录了沿地图绕行的真实路程。三角不等式给出另一个不会高估的下界。

h(v) = max( |xᵥ−xₜ| + |yᵥ−yₜ|, maxL |d(L,t)−d(L,v)| )

在同一连通分量内取最大值，仍满足 h(v) ≤ d(v,t) 与 h(v) ≤ 1+h(u)。断开的端点先由连通性检查判为不可达。
