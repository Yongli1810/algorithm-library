## 收录规范

按研究方向或算法大类建立子目录，再按论文或方法名称独立归档。各条目 README 建议注明：

- 论文题目、作者、发表信息和论文链接（有 DOI 时一并提供）。
- 算法原理、实现来源、代码许可和本仓库贡献者。
- 环境与依赖版本、数据来源、预处理方法及使用许可。
- 训练或运行命令、实验参数、随机种子和评价指标。
- 对比方法、实验结果、复现步骤与已知限制。
