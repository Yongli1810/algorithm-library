# kNN 机械狗人员编号识别

使用距离加权 kNN 识别已分割、归一化的 8×8 单个数字胸牌，并将数字 0—9 映射至虚构登记编号 P00—P09。
本条目是现有 [KNN 手写数字识别](../KNN手写数字识别/README.md) 的应用示例，核心识别方法相同，新增编号查询演示。

## 运行

在 `代码/` 目录执行：

```bash
python -m pip install numpy==2.3.5
python person_demo.py
```

完整识别实验入口为 `python run_experiment.py`。样本图绘制脚本另需 Pillow。

## 适用范围与数据来源

代码读取数字胸牌并查询登记编号，不包含人脸识别、相机胸牌定位、透视矫正或机械狗实机验证。
输入需预先准备成符合数据协议的单个数字。当前示例未设空白、未知输入的拒识机制，胸牌复制或转交无法据此区分。
投票占比未经概率校准，不等同于身份真实性验证。

测试数据来自 UCI Optical Recognition of Handwritten Digits，数据集作者 E. Alpaydin、C. Kaynak，许可 CC BY 4.0，DOI：10.24432/C50P49。完整署名及协议保留于包内 README.txt。
