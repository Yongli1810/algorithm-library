# 均值滤波去噪

对像素的局部邻域取平均，减弱随机亮度噪声。演示比较 3×3、5×5、9×9 窗口，观察去噪效果与边缘、细线损失。

## 使用方法

建议使用 Python 3.11 或更高版本。在 `代码/` 目录执行：

```bash
python -m pip install -r requirements.txt
python mean_filter_demo.py
```

默认生成合成图像和高斯噪声，无需下载数据或训练模型。结果写入 `results/`，包内已附结果图片及指标，可直接查看。
自选图片、窗口大小、噪声参数及依赖版本见原作者运行说明。重复运行可能覆盖同名结果，建议为新实验指定独立输出目录。

## 方法与限制

程序使用等权平均核与边缘复制补边。较大窗口能平均更多噪声，同时可能模糊边缘和细线，并不保证更高的 PSNR。
MSE、PSNR 需要干净参考图，自选图片没有参考时不计算这些指标。
