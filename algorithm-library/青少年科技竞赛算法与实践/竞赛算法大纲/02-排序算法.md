## 008 冒泡排序

**算法说明**　反复比较相邻元素，若顺序错误则交换，使较大或较小元素逐轮移动到最终位置。

**运行过程**

从头扫描相邻元素并交换逆序对；每轮确定一个边界元素，无交换时可提前结束。

**适用情形**　小规模数据、排序原理演示和近乎有序数据的基础教学。

**常用搭配**　相邻比较+交换；可用于理解逆序对和稳定排序。

**复杂度与边界**　平均/最坏O(n²)，优化后最好O(n)，空间O(1)，稳定。

**理解提示**　跟踪一轮扫描中的相邻比较结果，记录最大元素移动到末端的过程，并观察提前终止条件何时成立。

## 009 选择排序

**算法说明**　每轮从未排序区间中选出最小元素，与区间首元素交换。

**运行过程**

维护已排序前缀和未排序后缀；每轮扫描未排序部分确定最小值。

**适用情形**　数据量较小、交换次数需要控制的基础排序场景。

**常用搭配**　最小值查找+数组交换；可与插入排序比较。

**复杂度与边界**　最好/平均/最坏均O(n²)，空间O(1)，常规实现不稳定。

**理解提示**　把比较次数与交换次数分开统计，观察每轮未排序区间缩短的幅度，以及元素相对次序是否发生改变。

## 010 插入排序

**算法说明**　将当前元素插入前面已经有序的部分，逐步扩大有序区间。

**运行过程**

取出待插入元素，将较大元素向后移动，再把待插入元素放到空位。

**适用情形**　小规模或近乎有序数据；常作为混合排序的小区间处理方法。

**常用搭配**　插入排序+二分插入位置；TimSort/IntroSort的小数组优化。

**复杂度与边界**　最好O(n)，平均/最坏O(n²)，空间O(1)，稳定。

**理解提示**　取出待插入元素，逐项检查有序区间中哪些元素需要后移；插入位置由第一个不大于或不小于该元素的位置规则决定。

## 011 希尔排序

**算法说明**　按一定间隔对元素分组插入排序，逐步缩小间隔，最后执行间隔为1的插入排序。

**运行过程**

- 选择增量序列

- 对各间隔子序列执行插入排序

- 缩小增量直至1

**适用情形**　中等规模数组的原地排序，适合讲解插入排序改进。

**常用搭配**　分组插入排序+增量序列设计。

**复杂度与边界**　复杂度依赖增量序列；空间O(1)，通常不稳定。

**理解提示**　固定同一组数据，分别按不同增量序列执行分组插入，观察远距离元素移动对最终增量为 1 时比较次数的影响。

## 012 归并排序

**算法说明**　采用分治思想，将序列拆成两半排序，再合并两个有序序列。

**运行过程**

- 递归划分至单元素区间

- 分别排序

- 双指针合并两个有序部分

**适用情形**　大规模稳定排序、链表排序、外部排序和逆序对统计。

**常用搭配**　分治+递归、双指针、逆序对计数、外部归并。

**复杂度与边界**　时间O(n log n)，数组实现额外空间O(n)，稳定。

**理解提示**　将数组拆至单元素区间，再跟踪双指针合并；当两个待选元素相等时，检查取数顺序与稳定性之间的关系。

## 013 快速排序

**算法说明**　选择枢轴，将元素划分为小于和大于枢轴的区域，再递归处理子区间。

**运行过程**

- 选pivot

- 分区partition

- 确定枢轴位置或分区边界

- 递归排序左右部分

**适用情形**　通用内存排序、竞赛排序和需要高平均效率的数组排序。

**常用搭配**　分治+双指针分区、随机化枢轴、三数取中。

**复杂度与边界**　平均O(n log n)，最坏O(n²)，递归栈平均O(log n)，通常不稳定。

**理解提示**　用同一数组尝试不同枢轴位置，记录每次分区规模；左右子区间长期失衡时，递归深度和比较次数会同步增加。

## 014 堆排序

**算法说明**　利用二叉堆反复取出最大值或最小值，形成有序序列。

**运行过程**

- 建堆

- 交换堆顶与末尾

- 缩小堆范围

- 向下调整恢复堆性质

**适用情形**　需要原地排序且要求最坏O(n log n)时间的场景。

**常用搭配**　完全二叉树+堆调整、优先队列。

**复杂度与边界**　建堆O(n)，排序O(n log n)，额外空间O(1)，不稳定。

**理解提示**　把堆按数组下标展开，核对父子节点关系；每次交换堆顶后，只需检查受影响节点的堆序是否恢复。

## 015 计数排序

**算法说明**　统计每个整数键值出现的次数，再按键值顺序输出元素。

**运行过程**

- 确定键值范围

- 统计频次

- 计算累计频次或直接重复输出

- 恢复有序序列

**适用情形**　取值范围较小的整数排序，如分数、年龄和有限类别编码。

**常用搭配**　频次统计+累计计数；稳定版本常用于基数排序。

**复杂度与边界**　时间O(n+k)，空间O(n+k)或O(k)；适合值域k可控的整数；稳定版本需累计计数。

**理解提示**　根据最大值与最小值确定计数数组长度，再比较值域 k 与元素数 n，判断频次数组的空间成本是否合适。

## 016 基数排序

**算法说明**　按关键字各位或各字符位逐轮排序，将多位排序拆成多个稳定的单关键字排序。

**运行过程**

- 确定位数和进制

- 从低位到高位或高位到低位排序

- 每轮使用稳定排序

**适用情形**　非负整数、定长字符串和固定格式编码。

**常用搭配**　基数排序+稳定计数排序、桶排序。

**复杂度与边界**　LSD实现常见O(d(n+k))，空间O(n+k)，d为位数。

**理解提示**　逐位检查排序后的相对次序，重点确认每一轮采用稳定排序；前一位形成的顺序依赖后续轮次保留。

## 017 桶排序

**算法说明**　将数据按值域分配到多个桶中，桶内分别排序，再按桶顺序合并。

**运行过程**

- 确定桶区间

- 分配元素

- 桶内排序

- 按桶序连接结果

**适用情形**　数据分布较均匀的浮点数或区间数值排序。

**常用搭配**　桶排序+插入排序、计数排序和分布估计。

**复杂度与边界**　均匀分布下期望可接近O(n+k)，最坏可能O(n²)，空间O(n+k)。

**理解提示**　改变数据分布并保持元素数量不变，观察桶内负载和桶内排序成本如何影响总体运行时间。

## 018 鸡尾酒排序

**算法说明**　冒泡排序的双向版本，每轮交替从左向右和从右向左扫描。

**运行过程**

正向扫描将最大值推向右端，反向扫描将最小值推向左端，逐步缩小未排序区间。

**适用情形**　近乎有序且局部逆序分布特殊的小数组教学。

**常用搭配**　冒泡排序+双向扫描。

**复杂度与边界**　平均/最坏O(n²)，最好优化后O(n)，空间O(1)，稳定。

**理解提示**　分别记录正向扫描和反向扫描后的有序边界，观察双向移动对局部逆序分布的处理效果。

## 019 梳排序

**算法说明**　通过较大的间隔比较并交换元素，逐步缩小间隔，减少小值向前移动的拖延。

**运行过程**

- 初始化gap

- 比较相距gap的元素

- 交换逆序元素

- 缩小gap

- gap为1且无交换时结束

**适用情形**　作为冒泡排序改进方法的算法学习与比较。

**常用搭配**　冒泡排序+间隔缩小。

**复杂度与边界**　最坏O(n²)，实际通常优于冒泡；空间O(1)，不稳定。

**理解提示**　从较大的 gap 开始追踪远距离元素交换，再逐步缩小间隔，关注 gap=1 阶段仍需完成的比较与交换。

## 020 TimSort

**算法说明**　结合归并排序与插入排序的稳定混合排序，利用输入中已有的有序段提升效率。

**运行过程**

- 识别自然有序run

- 短run用插入排序扩展

- 按规则合并run并保持稳定

**适用情形**　通用对象排序和部分有序数据。

**常用搭配**　自然归并+二分插入、归并策略。

**复杂度与边界**　最坏O(n log n)，近乎有序时可接近O(n)，稳定，需额外空间。

**理解提示**　识别输入中的自然有序 run，检查短 run 的扩展方式及相邻 run 的合并条件，理解算法如何利用已有顺序。

## 021 内省排序（Introsort）

**算法说明**　结合快速排序、堆排序和插入排序，兼顾平均效率与最坏情况保证。

**运行过程**

先用快速排序；递归深度超过阈值时切换堆排序；小区间改用插入排序。

**适用情形**　通用高性能原地排序库实现。

**常用搭配**　快速排序+堆排序+插入排序。

**复杂度与边界**　最坏O(n log n)，平均O(n log n)，额外空间通常为递归栈，通常不稳定。

**理解提示**　跟踪快速排序递归深度，达到阈值时核对堆排序切换条件；小区间改用插入排序后，整体最坏界仍受控。

## 022 外部归并排序

**算法说明**　当数据量超过内存容量时，分批排序后写入外存，再多路归并得到全局有序结果。

**运行过程**

- 分块读入内存

- 各块内部排序

- 生成有序文件段

- 多路归并

**适用情形**　超大文件、数据库排序和大规模日志处理。

**常用搭配**　内存排序+多路归并+优先队列。

**复杂度与边界**　主要成本为磁盘I/O轮数和归并路数；比较次数通常与N log N相关。

**理解提示**　按内存容量划分数据块，分别记录初始归并段数量、每轮归并路数和磁盘读写次数，区分计算与 I/O 开销。
