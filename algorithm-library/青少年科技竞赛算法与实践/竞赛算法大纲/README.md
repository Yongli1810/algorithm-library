# 竞赛算法大纲

本页按《计算机算法知识汇编》的原有分类整理，包含 **15 个知识领域、221 项算法与相关方法**。点击分类可直接阅读正文，再点击条目名称定位到具体算法，无需下载 Word。

每个条目保留原文的算法说明、运行过程、适用情形、常用搭配、复杂度与边界、理解提示。此处是知识大纲，现有可运行算法和演示材料请查看[青少年算法索引](../README.md#算法索引)。

该范围来自用户整理的学习资料，未逐项核验为各赛事的官方指定或必考范围；具体参赛范围以相应赛事和组别的大纲为准。

## 如何阅读

1. 先从分类中选择一个知识领域，进入该类的条目目录。
2. 点击算法名称，阅读说明、运行过程和适用条件。
3. 对照理解提示，核对初值、更新规则、终止条件与复杂度前提。
4. 需要运行示例时，返回[现有算法索引](../README.md#算法索引)查找相应资源。
