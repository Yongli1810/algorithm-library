# 术语与复杂度说明

[返回大纲首页](README.md)

**算法**　为完成某项计算任务而设计的有限步骤方法，重点在于输入、处理过程和输出结果。

**数据结构**　组织和维护数据的方式。栈、队列、堆、并查集、树状数组和线段树均属于数据结构。

**算法设计思想**　组织求解过程的通用策略，如枚举、分治、贪心、回溯和动态规划。

**模型与网络架构**　线性回归、SVM、CNN、Transformer等用于表示或学习数据关系；梯度下降、反向传播等承担参数优化任务。

**系统方法**　SLAM、机器人路径规划和多传感器融合通常由多个算法协同完成，需结合系统流程理解。

**时间复杂度**　描述输入规模增长时，算法执行步骤数量的渐近变化。

**空间复杂度**　描述运行过程中额外存储需求的渐近变化；递归方法还需计入调用栈。

**复杂度前提**　复杂度结论与实现方式、数据结构和输入条件有关。阅读时应同时核对算法条目中的限制条件。

## 常见时间复杂度

**O(1)**　常数级：操作次数不随输入规模增长。

**O(log n)**　对数级：每轮缩小问题规模，常见于二分查找。

**O(n)**　线性级：通常需要遍历一次输入数据。

**O(n log n)**　线性对数级：常见于归并排序、堆排序等比较排序。

**O(n²)**　平方级：常见于两层嵌套遍历。

**O(2ⁿ)**　指数级：常见于枚举子集或部分状态搜索。

**O(n!)**　阶乘级：常见于枚举全部排列。
